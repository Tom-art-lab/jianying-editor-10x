# 剪映字幕参数标定（字号 / 垂直位置 → 实际像素）

> 剪映的 `TextStyle.size` 与 `ClipSettings.transform_y` **没有官方像素换算说明**，
> 不同版本可能不同。换版本或换字体后应重新标定一次。
> 标定环境：剪映 10.5.0.13988 / Windows / 画布 1080×1920 / 字体 Poppins_Bold。

## 一、标定公式（本机实测）

```
白字高(px, 1080×1920 画布)  = 7.5 + 2.4 × size
画面高度百分比(%)          = 49.76 − 49.8 × transform_y
```

推导依据（4 条标定字幕，实测）：

| size | transform_y | 实测白字高 | 实测画面位置 |
| --- | --- | --- | --- |
| 15 | 0.7 | 43.5 px | 14.9 % |
| 11 | 0.2 | 33.9 px | 39.8 % |
| — | -0.3 | — | 65.0 % |
| — | -0.8 | — | 92.3 % |

位置公式的截距 ≈ 49.76%（≈ 画面中心），说明 `transform_y` 是
**相对画面中心的归一化偏移**，范围约 ±1（±100% 画面高）。

## 二、标定步骤

1. 建标定草稿，放 4 条**同一文本、不同 size / transform_y** 的字幕。
   **每条必须放独立文字轨**（`Subtitles1`…`Subtitles4`）——同一轨不允许时间重叠，
   否则报 `New segment overlaps with existing segment`。
2. 用 `scripts/tools/jy_gui.py` 打开该草稿，截图预览区。
3. 定位画布区域，计算 `scale = 画布显示高 / 1920`：
   ```python
   reg = a[y0:y1, x0:x1]
   blk = reg.max(axis=2) < 18          # 纯黑画布
   # 校验 宽高比 ≈ 0.5625 (1080/1920)
   ```
4. 检测字幕行：`white = min(RGB) > 225` 且 `binary_dilation(dark, 3)` 附近，
   按行统计找连续段，换算 `px = 显示px / scale`。
5. 两点即可定直线（实测线性度很好）。

参考实现：`scripts/tools/sticker_to_overlay.py` 同目录思路，
标定脚本见会话产物 `_calib_sub.py`。

## 四、坑

- **画布尺寸随布局变化**：时间轴展开后预览画布从 397px 高缩到 288px，
  每次测量前都要重新定位边界，不能复用上次的 scale。
- **全大写文本比句子式宽约 15~20%**。全大写 + size=19 时，27 字符文案会超出
  1080px 画布宽。配合 `auto_wrapping=True, max_line_width=0.86` 可自动换行。
- 预览区截图的精度受画布显示尺寸限制（画布高 <300px 时，1 显示像素 ≈ 6.7 实际像素），
  标定时尽量让画布显示得大一些（收起时间轴 / 窗口最大化）。
